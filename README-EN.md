# Mobile Quality Engineering Lab

A senior-level portfolio project that demonstrates how a Quality Engineering and SDET team can design, automate, validate, and govern mobile quality across Android and iOS.

## Why this project exists

This repository models a realistic quality engineering operating model for critical mobile journeys. The emphasis is not on building a production app, but on demonstrating how to structure a robust mobile testing strategy with engineering discipline, automation evidence, and release confidence.

## What is included

- TypeScript-first automation foundation
- Appium 2 + WebdriverIO architecture
- Screen Object Pattern and reusable abstractions
- API contract and schema validation
- Retry and failure handling patterns
- BDD and behavior-oriented scenarios
- Azure DevOps pipeline design
- Cloud device farm strategy
- Evidence bundle and environment-based release gating

## Quality focus areas

- authentication validation
