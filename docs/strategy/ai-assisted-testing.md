# AI-Assisted Testing

## Safe usage for quality engineering

AI can support test design and quality workflows, but human review remains mandatory for approval of critical changes and release decisions.

### Supported uses
- Requirement analysis
- Risk identification
- Test case generation
- Edge-case discovery
- Test data generation
- Code refactoring suggestions
- Failure analysis
- Locator maintenance suggestions

### Guardrails
- No automatic approval of production-critical changes
- Human review of generated locators and assertions
- Clear evidence trail for outputs
- Sensitive data must never be included in prompts
