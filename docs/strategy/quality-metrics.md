# Quality Metrics

## Calculations
- Pass Rate = Passed / Total
- Automation Coverage = Automated requirements / Total requirements
- Defect Leakage = Defects found after release / Total defects
- Flaky Rate = Flaky tests / Total tests
- Execution Time = Total duration of relevant suites
- Critical Flow Coverage = Critical flows automated / total critical flows
- Failure Distribution = Failures grouped by type, platform, and test area

## Reporting
Keep metrics in dashboards or exported JSON/CSV summaries for trend analysis across releases.
