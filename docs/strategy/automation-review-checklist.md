# Automation Review Checklist

- Duplicate code or repeated workflow logic
- Flaky waits or sleep-based synchronization
- Hard-coded values without environment or fixture configuration
- Weak or unstable locators
- Missing assertions
- Missing cleanup and reset logic
- Excessive E2E coverage in low-risk flows
- Security issues in logs, tokens, or storage
- Weak typing or missing validation
- Poor naming or unclear intent
