# Mobile Testing Interview Guide

## Web testing vs mobile web vs native vs hybrid

- Web testing targets browsers in desktop or mobile browser contexts.
- Mobile web focuses on web content running in browser-based mobile experiences.
- Native apps use device OS frameworks and platform-specific behavior.
- Hybrid apps embed web content inside a native shell, which introduces cross-context testing complexity.

## Key considerations
- Device fragmentation
- OS version support
- Permissions and app lifecycle
- Network conditions and interruption scenarios
- Different input methods and orientation behaviors
