# Mobile Quality Engineering Lab

This personal technical project demonstrates a modern Quality Engineering approach for Android and iOS automation. It combines Appium, Maestro, Robot Framework, API testing, risk-based coverage, CI/CD integration, and quality metrics into a reusable reference architecture for critical mobile journeys.

The lab focuses on authentication, onboarding, workflows, and high-risk mobile operations while emphasizing observability, maintainability, accessibility, and execution strategy across environments and device coverage tiers.
