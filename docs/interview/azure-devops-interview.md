# Azure DevOps Interview Guide

## Why Azure DevOps
Azure DevOps provides unified pipeline orchestration, artifact publishing, environment control, and governance for quality flow execution.

## Relevant capabilities
- Pipelines for build, validation, and test execution
- Quality gates and policy enforcement
- Test reporting and artifact storage
- YAML-driven reproducibility

## Senior QA perspective
Use pipeline stages to ensure static validation, smoke coverage, critical regression, and release evidence are generated before promoting changes.
