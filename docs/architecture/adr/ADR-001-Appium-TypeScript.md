# ADR-001: Appium with TypeScript

## Status
Accepted

## Context
The project requires a robust cross-platform mobile automation approach for Android and iOS. It also needs maintainability and static validation.

## Decision
Use Appium 2 with TypeScript and WebdriverIO-compatible patterns for UI automation.

## Consequences
- Strong typing and maintainability
- Cross-platform automation support
- Clear separation of UI logic from test scenarios
- Requires Appium server and device or emulator setup
